三個步驟開始使用

第一次開啟 Deskdo 會出現設定精靈，大約 2 分鐘，不需要打任何指令。

  1. 下載並安裝

    安裝在目前的使用者底下，不需要系統管理員權限。

  2. 登入 Cloudflare

    還沒有帳號就免費註冊一個。Deskdo 會在你的帳號自動建立存放待辦的雲端。

  3. 連接 Claude

    把精靈給你的網址貼到 claude.ai 的「自訂連接器」，網頁版和手機版就都能用了。

你的資料，只在你的帳號裡

Deskdo 沒有自己的伺服器。桌面 App 和 Claude 讀寫的，都是你 Cloudflare 帳號裡的小程式和資料庫。

常見問題

需要付費嗎？

不需要。Deskdo 免費且開源；Cloudflare 免費方案每天可以處理 10 萬次請求，一台開著 Deskdo 的電腦每天大約只用 3 千次。 claude.ai 的自訂連接器則依照 Anthropic 的方案規定。

為什麼要用 Cloudflare 帳號？

為了讓桌面和 Claude 讀寫同一份待辦，資料需要放在網路上。放在你自己的帳號裡，你就擁有完整的控制權： 不用信任第三方伺服器，也不會因為某個服務關閉而失去資料。

Deskdo 會用我的 Cloudflare 權限做什麼？

只會建立和更新一個名為 deskdo 的 Worker 與同名的 D1 資料庫，並在第一次使用時開啟你帳號的 workers.dev 網址。不會讀取或修改帳號裡的其他東西。程式碼都公開在 GitHub 上，可以自己檢查。

Windows 顯示「Windows 已保護您的電腦」怎麼辦？

這是因為 Deskdo 還沒有購買程式碼簽章憑證，新的、下載次數少的程式都會出現這個提示。點「其他資訊」→「仍要執行」即可安裝。

可以在好幾台電腦上使用嗎？

可以。在另一台電腦安裝 Deskdo，用同一個 Cloudflare 帳號登入，就會自動連到同一份待辦。不用的電腦可以在「設定 → 已連線的電腦」移除。

有 Mac 版或手機 App 嗎？

目前只有 Windows 版。手機上可以透過 Claude App 新增和查看待辦，連接器設定一次就會自動同步到手機。

連接器網址不小心外流了怎麼辦？

到 Deskdo 的「設定 → claude.ai 連接器」按「更換網址」，舊網址會立即失效，再把新網址貼回 claude.ai 即可。
