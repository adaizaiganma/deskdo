三個步驟開始使用

第一次開啟 Deskdo 會出現設定精靈，大約 2 分鐘，不需要打任何指令。

  1. 下載並安裝

    電腦版安裝在目前的使用者底下，不需要系統管理員權限；Android 下載 APK 安裝。iPhone、iPad 不用安裝，用網頁版。

  2. 登入 Cloudflare

    還沒有帳號就免費註冊一個。Deskdo 會在你的帳號自動建立存放待辦的雲端。

  3. 連接 AI 助理（可略過）

    把精靈給你的網址貼到 Claude、ChatGPT 等 AI 助理的「自訂連接器」。不用 AI 的話，這步直接跳過。

你的資料，只在你的帳號裡

Deskdo 沒有自己的伺服器。App、網頁版和 AI 助理讀寫的，都是你 Cloudflare 帳號裡的小程式和資料庫。

Deskdo電腦、手機 App、網頁版

Deskdo 的開發者看不到、也碰不到你的待辦。登入 Cloudflare 的憑證只在設定精靈執行時使用，不會存到硬碟。 詳細說明請看隱私說明。

常見問題

不用 AI 也能用嗎？

可以。桌面小工具、主視窗、快速新增、手機 App、多台裝置同步都不需要 AI。設定精靈最後的「連接 AI 助理」直接略過即可，之後想接再到設定裡找網址。

可以用 ChatGPT 嗎？

Deskdo 提供標準的 MCP 連接器，ChatGPT 在「開發者模式」可以加入自訂連接器。要注意：新增、修改待辦需要 ChatGPT 支援可寫入的連接器， 部分方案可能只能查詢；每次修改前 ChatGPT 會請你確認。設定方式請看使用說明。

需要付費嗎？

不需要。Deskdo 免費且開源；Cloudflare 免費方案每天可以處理 10 萬次請求，一台開著 Deskdo 的電腦每天大約只用 3 千次。 AI 助理的自訂連接器則依各家的方案規定。

為什麼要用 Cloudflare 帳號？

為了讓電腦、手機和 AI 助理讀寫同一份待辦，資料需要放在網路上。放在你自己的帳號裡，你就擁有完整的控制權： 不用信任第三方伺服器，也不會因為某個服務關閉而失去資料。

Deskdo 會用我的 Cloudflare 權限做什麼？

只會建立和更新一個名為 deskdo 的 Worker 與同名的 D1 資料庫，並在第一次使用時開啟你帳號的 workers.dev 網址。不會讀取或修改帳號裡的其他東西。程式碼都公開在 GitHub 上，可以自己檢查。授權畫面上 Workers 會顯示「管理」權限，原因請看隱私說明。

Windows 顯示「Windows 已保護您的電腦」怎麼辦？

這是因為 Deskdo 還沒有購買程式碼簽章憑證，新的、下載次數少的程式都會出現這個提示。點「其他資訊」→「仍要執行」即可安裝。

手機可以用嗎？

可以。Android 有 App：到 GitHub 下載 Deskdo_…_arm64.apk 安裝，主畫面還有小工具，可以直接打勾完成。 iPhone、iPad 用網頁版：在電腦或 Android 的「設定 → 在 iPhone、iPad 使用」產生配對碼，用相機掃 QR code 打開，加到主畫面後輸入配對碼，之後就像 App 一樣從主畫面打開。

為什麼 iPhone 沒有 App？

Deskdo 目前沒有上架 App Store，iPhone、iPad 請用網頁版。網頁版由你自己的雲端提供，資料一樣只在你的帳號裡；配對一次之後就不用再輸入配對碼。

有 Mac 版嗎？

目前沒有。Mac 上可以用瀏覽器開網頁版（一樣用配對碼），介面和電腦版的主視窗一樣，只是沒有桌面小工具。

可以在好幾台電腦、手機上使用嗎？

可以。在其他電腦或 Android 手機安裝 Deskdo，用同一個 Cloudflare 帳號登入，就會自動連到同一份待辦；iPhone、iPad 用配對碼。不用的裝置可以在「設定 → 已連線的裝置」移除。

會自動更新嗎？

會。電腦版在背景下載新版，按「重新啟動並更新」就好；Android 會在主畫面提示，按一下下載安裝，資料都會保留；網頁版跟著你的雲端更新。 有些新版需要更新雲端，畫面上會出現「雲端有新版本」，按一下並登入 Cloudflare 即可，資料不會變動。

連接器網址不小心外流了怎麼辦？

到 Deskdo 的「設定 → AI 連接器」按「更換網址」，舊網址會立即失效，再把新網址貼回 AI 助理即可。
